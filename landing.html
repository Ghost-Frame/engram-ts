Features

Everything agents need to remember

One server. One libsql database. Runs on Node.js 22+ or Bun. No external services required.

Smart Memory
⌛

FSRS-6 Spaced Repetition

21-parameter algorithm trained on millions of Anki reviews. Power-law forgetting curves. Every access is an implicit review. Stability grows over time.

💪

Dual-Strength Model

Bjork & Bjork (1992): storage strength never decays, retrieval strength resets on access. Combined retention score: 0.7 x retrieval + 0.3 x storage.

🔄

Versioning

Update memories without losing history. Full version chain preserved. Only the latest version surfaces in search and recall.

🧹

Auto-Deduplication

SimHash 64-bit locality-sensitive hashing detects near-identical memories and merges them. Source count tracks how often something was mentioned.

⏰

Auto-Forget / TTL

Set memories to expire with forget_after. Background sweep every 5 minutes. Critical memories persist forever.

⚡

Contradiction Detection

LLM-verified conflict scanning eliminates false positives. Resolve by keeping one side, both, or merging into a single memory.

Intelligence Layer
🧠

Hybrid Semantic + FTS5

4-channel Reciprocal Rank Fusion: BGE-large vector similarity, FTS5 full-text, personality signals, and graph relationships. Cross-encoder reranking (BGE-reranker-base INT8). No OpenAI key required.

🔍

Fact Extraction & Auto-Tagging

LLM extracts static facts from conversations. Auto-tags with keywords, classifies importance, detects relationship types (updates, extends, contradicts, caused_by).

💬

Conversation Extraction

Feed raw chat logs to /add. Get structured memories out. Works with any agent framework or raw message arrays.

🌐

URL Ingest

Point /ingest at a URL or paste raw text. Facts extracted and stored automatically with source tracking.

💭

Reflections

On-demand meta-analysis detects themes, patterns, and progress across your memory space. Reflections become searchable memories.

🤮

Derived Memories & Consolidation

LLM inference finds patterns across clusters and generates new knowledge. Auto-consolidation compresses large clusters into dense memories.

🚫

Abstention

Search returns abstained: true when confidence is below threshold. The system knows what it doesn't know. No more false positives on unrelated queries.

🤖

Assistant Recall

Extracts what the AI said, recommended, and produced, not just user facts. LLM + regex patterns capture assistant actions as structured facts.

🎭

Personality Engine

Extracts six signal types from conversations: preferences, values, motivations, decisions, emotions, identity. LLM synthesizes a coherent profile that shapes future recall scoring.

🛡

Guardrails

Agents call /guard before destructive actions. Engram checks stored rules for conflicts and returns allow/warn/block, preventing repeated mistakes before they happen.

Developer Platform
🔧

MCP Server

Native Model Context Protocol. JSON-RPC 2.0 stdio. Works with Claude Desktop, Cursor, and Windsurf out of the box. 8 tools, 3 resources.

⌨

CLI

engram-cli store, engram-cli search, engram-cli context and more. Full access to every feature from your terminal. Supports --json and --quiet output modes.

👥

Multi-Tenant + RBAC

Isolated memory per user. Role-based access: admin, writer, reader. Per-key rate limiting, scoped permissions, API key management.

📬

Webhooks & Digests

Event hooks on every mutation with HMAC signing. Scheduled memory digest delivery. Built-in SSRF protection on webhook URLs.

🔄

Cross-Instance Sync

Pull changes since a timestamp, push to another instance. Keep multiple Engram deployments in sync across environments.

📋

Audit Trail & Structured Logging

Every mutation logged: who, what, when, from where, with request IDs. Queryable via /audit. JSON logs throughout.

📝

Scratchpad / Working Memory

Ephemeral per-session storage with TTL auto-purge. Promote entries to permanent memories when they prove valuable. Injected into /context as a working memory layer.

How It Works

The memory lifecycle

From store to recall: what happens to every memory.

01
💾

Store

Content embedded via BGE-large ONNX (1024-dim), stored in libsql with FTS5 full-text indexing.

02
🔗

Auto-Link

Compared to existing memories. Above 0.55 cosine similarity, typed relationship edges are created automatically.

03
⌛

FSRS-6 Init

Stability, difficulty, storage + retrieval strength initialized. Power-law forgetting curve begins tracking retrievability.

04
🔍

Fact Extract

If LLM configured: static facts extracted, keywords tagged, importance scored, relationships to existing memories detected.

05
🎯

Recall

Multi-layer context assembly: static facts, semantic matches, episodic context, graph expansion, recent activity, working memory, personality signals, and implicit inference.

06
📈

Review

Every recall is an implicit FSRS-6 "Good" review. Stability builds. Frequently recalled memories can reach months of retention.

07
💪

Dual Decay

Storage strength accumulates. Retrieval strength decays via power law. Combined: 0.7 x retrieval + 0.3 x (storage/10).

08
⚡

Contradiction

Conflicts detected and LLM-verified. Resolved by keeping one, both, or merging. False positives eliminated automatically.

09
📜

Consolidate

Large related clusters summarized into a single dense memory. Originals archived, graph links preserved.

10
💭

Reflect

Periodic meta-analysis generates insights about themes, progress, and patterns. Reflections become searchable memories.

SDKs

Three lines to persistent memory

TypeScript SDK, CLI, or raw HTTP. Pick your weapon.

TypeScript npm install @ghostframe/engram
const mem = new Engram({
  url: "http://localhost:4200",
  apiKey: "eg_...",
});

await mem.store("Auth migrated to JWT", {
  category: "decision", importance: 9,
});

const ctx = await mem.recall("authentication setup");

// Check FSRS memory health
const fsrs = await mem.fsrsState(id);
// { retrievability: 0.94, stability: 6.2 }
CLI npm install -g @ghostframe/engram
# Store a memory
engram-cli store "Auth migrated to JWT" \
  --category decision --importance 9

# Search with explanation
engram-cli search "auth setup" --explain

# Budget-aware context for RAG
engram-cli context "auth setup" \
  --budget 2000

# All commands support --json output
cURL raw HTTP
# Store a memory
curl -X POST localhost:4200/store \
  -H "Authorization: Bearer eg_..." \
  -d '{"content":"Auth migrated",
      "category":"decision",
      "importance":9}'

# Contextual recall
curl -X POST localhost:4200/context \
  -d '{"query":"auth setup",
      "budget":2000}'
MCP Server

Works with your AI tools

Native Model Context Protocol. Drop Engram into Claude Desktop, Cursor, or Windsurf in under a minute.

JSON claude_desktop_config.json
{
  "mcpServers": {
    "engram": {
      "command": "node",
      "args": ["--experimental-strip-types", "path/to/engram/mcp-server.ts"],
      "env": {
        "ENGRAM_URL": "http://localhost:4200",
        "ENGRAM_API_KEY": "eg_your_key"
      }
    }
  }
}
